# アプリの使い方

アプリだけで練習は完結する（ChatGPT は不要）。

```sh
uv run python gui.py      # http://127.0.0.1:8792/ が開く（PRON_GUI_PORT で変更可）
```

## 流れ

1. 「＋ 原稿」で原稿を登録する（お手本の生成が始まる）。
2. 録音ボタンで発表を録る。停止すると自動で解析される。
3. 「分析を見る」で、赤い印のある語をクリックしてお手本と聴き比べる。
4. 気になる文は「この文を録り直す」で、良くなるまでその場で確かめる。

## 原稿の登録と修正

- **「＋ 原稿」**：英文を貼るか .txt / .md をドロップすると、1 行 1 文に自動で分ける（e.g. や et al. では切らない。Markdown の記号や日本語のメモは除く）。`#` 見出しがあれば見出しごとに別の原稿（`01-cover` など）にする。プレビューで確認・選択してから保存する。
- **原稿カード**：選んだ原稿の全文を表示する。「大きく表示」で録音中に読みやすくなる。「修正」で本文を直し、「確定」で保存、「取消」で元に戻す。確定したとき内容が変わっていれば 1 行 1 文に分け直し、変わった文のお手本だけ作り直す。
- 前の版は `slides/.history/` に残り、`#` のメモ行は消えない。
- 録音は開始時点の原稿を保存しているので、録音中に直しても採点はずれない。

原稿のファイルは `slides/<名前>.txt`（1 行 1 文、`#` で始まる行はメモ）。`slides/` は git の管理対象外。

## お手本

`uv sync --extra reference` を入れると、原稿の 1 文ずつをローカルの TTS（Kokoro-82M）が読み上げ、同じ方法で解析しておく。2 回目以降はキャッシュを使う。声は環境変数 `PRON_TTS_VOICE`（既定 `af_heart`、アメリカ英語）で変えられる。

## 分析画面

履歴の「分析」、または録り終えた直後の「分析を見る」から開く。

- 文ごと・語ごとに、ピッチ曲線（自分: 実線、お手本: 破線）・単語・正しい IPA・聞こえた IPA を縦に並べ、ずれた音・強勢・抜けを赤で示す。
- 語をクリックするとその語を自分 → お手本の順に、文の ▶ でその文だけを再生する。
- 日本語のアドバイスを重要な順に 4 件まで出し、残りは折りたたむ。
- お手本はその録音のときの原稿の版から作るので、あとで原稿を直しても対応はずれない。

## 1 文の録り直し

分析画面の各文の「● この文を録り直す」で 1 文だけ録り直し、その場で採点して元の録音の下に並べる（点数の推移、語ごとの IPA とピッチ、アドバイス）。

録り直しの音声は保存しない。聴き返し用に最新 1 回分だけを一時ファイルに置き、次の録り直しか GUI の終了で消す。履歴にも ChatGPT にも残らない。

## CLI

```sh
uv run python pron.py record slides/cover.txt             # Enter で録音停止 → そのまま解析
uv run python pron.py analyze talk.flac slides/cover.txt  # 既存の音声を取り込む
uv run python pron.py analyze --id cover-003              # 解析だけやり直す
uv run python pron.py list
```

## 保存先と安全性

- 結果は `data/pron.db`（SQLite）、音声は `data/audio/`。保存先は `PRON_DATA_DIR`、原稿の置き場は `PRON_SLIDES_DIR` で変えられる。
- GUI は 127.0.0.1 だけで待ち受け、起動ごとの使い捨てトークンと Host ヘッダーを確かめる。ほかのウェブページから録音を始めたり消したりはできない。
- 録音には PipeWire の `pw-record` を使う（Linux）。
